Liquid Composer

Privacy Policy

Last updated October 31, 2026

Liquid Composer is an independent project by Eddu. It has no accounts, cookies or ads, and it does not sell or share personal data. This policy covers the web editor at liquid-composer.vercel.app, its MCP server at liquid-composer.vercel.app/mcp and the liquid-composer command-line tool on npm.

The web editor

  • The editor runs in your browser. Your artwork, layers and settings are kept in your browser's storage (localStorage and IndexedDB) so your work survives a reload. They are never uploaded to us.
  • Exports (PNG, JPEG, ZIP and .icon) are created in your browser and saved straight to your device.
  • The editor keeps a copy of its own files in your browser so it can open offline, including when installed as an app. This copy holds no personal data.
  • Reset Document deletes the saved icon, and turning off Auto-save stops saving it until you reload. Clearing this site's data in your browser removes everything, including recent colors.
  • Links that open an icon carry its recipe after the # in the address. Browsers don't send that part to the server.

Analytics

The editor counts visits with Vercel Web Analytics, which uses no cookies and doesn't identify you. Each page view records the page address without the part after #, the referring site, an approximate location (country, region and city), and the browser, operating system and device type. Visitors are told apart by a hash of the request that is discarded after 24 hours. Pages opened by AI agents (with ?agent in the address), the MCP server and the command-line tool send no analytics.

The MCP server

When an AI assistant such as Claude uses the Liquid Composer connector, it sends the server the arguments of each tool call: an icon recipe with layer names, colors, glass settings and artwork as inline SVG or image data. The server checks the recipe or turns it into a link and sends the result back. Recipes are handled in memory and discarded once the response is sent. The server never receives your conversation, only the tool arguments, and it requires no sign-in.

The command-line tool

The liquid-composer npm package runs on your computer and renders icons with your own copy of Google Chrome. Recipes, artwork and renders stay on your machine and are never sent to us.

Sharing and service providers

We don't sell, rent or share personal data. The editor and the MCP server are hosted on Vercel, which also provides the analytics and, like any web host, processes technical data about each request, such as IP address, browser and time, to deliver and protect the service, as described in Vercel's privacy policy. The command-line tool is downloaded from the npm registry, which has its own privacy policy.

Retention

  • Recipes sent to the MCP server are not kept.
  • Data in your browser stays until you delete it.
  • Analytics are kept by Vercel in aggregate, for the reporting window of the project's plan.
  • Request records at Vercel follow Vercel's retention rules and are used only to run the service.
